# ハロウィンまちがいさがし

ひだりと みぎの 絵をくらべて、ちがうところをタップして探す、子ども向けのまちがいさがしゲームです。怖くない、かわいいハロウィンの雰囲気にしています。

公開URL（予定）: https://altogrow-ir.github.io/halloween-machigai-sagash/

## 遊び方

- モードを選びます
  - かんたん（まちがい 3つ）
  - ふつう（まちがい 5つ）
- 絵は絵文字を 4列×3行 に並べた場面です。場面は「おばけやしき」「かぼちゃばたけ」「まほうのもり」の3種類からランダムに出ます
- ラウンドごとに、どのマスが・どんな差分になるかはランダムに決まります（毎回ちがいます）
  - 絵文字が別の絵文字に変わっている
  - 要素が消えている（みぎの え だけ空っぽ）
  - 要素が増えている（何もなかったマスに、みぎの え だけ絵文字がある）
  - 要素の大きさがちがう（大きい／小さい）
- ちがうところを見つけたら、そのマスをタップします。ひだりの え でも みぎの え でも、どちらの絵をタップしても正解になります
- 正解したマスには ✓ の印とオレンジの枠が付きます。まちがった場所をタップしても罰はなく、軽く揺れて「そこは おなじだよ」と表示されるだけです
- 画面に「みつけた：2/5」のような見つけた数、タイマー（経過時間）、あと何個かを応援する文が出ます
- 全部見つけたらクリア画面になり、かかった時間と「もういちど」ボタン（同じモードで新しい絵）・「モードを えらぶ」ボタンが出ます
- ひらがな多めのやさしい日本語で、ボタンや文字は大きくしています。スマホでは左右の絵が上下に並びます

## 記録

- クリア回数と、モード別（かんたん／ふつう）のベストタイムを `localStorage` のキー `halloween-machigai-sagashi-save-v1` に保存し、画面の上のほうに表示します
- サーバーは使わず、ブラウザ（端末内）だけで完結します

## 構成

- Vite + React 19 + TypeScript（ESM、npm）
- ルート：`index.html` / `vite.config.ts`（base は `"/halloween-machigai-sagash/"`）/ `tsconfig.json` / `package.json`
- 実装の中心：`src/App.tsx`（＋ `src/main.tsx`、`src/App.css`、`src/index.css`）
- 外部画像素材は使わず、絵文字＋CSSで表現しています

## 開発・ビルド

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # tsc -b && vite build（dist/ に出力）
npm run preview  # ビルド結果の確認
```

## 公開

- ビルド成果物を `docs/` フォルダにコピーし、GitHub Pages の公開元を `main` ブランチの `/docs` に設定して公開します（ワークフロー方式は使いません）
